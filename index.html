School Management System

Laravel 11 (Blade) + Bootstrap 5 + MySQL. This project runs as a container — see README.md.

  • docker build -t school-mgt . && docker run -p 8000:8000 school-mgt
  • Then open http://localhost:8000 (public site) and /login (admin panel).
  • Demo logins (password password): admin@school.com, teacher@school.com, student@school.com, parent@school.com
